# 90-Second Demo Video Script

**[0:00 - 0:10] Hook & Intro**
*Visual: Fast cuts of the 3D cards swiping left and right on mobile.*
*Voiceover:* "Have you ever gotten into a debate about the best web framework? Now you can settle it with math. Welcome to Tiebreak."

**[0:10 - 0:30] The Arena**
*Visual: Desktop view of the `/dev-tools` arena. User uses arrow keys to rapidly vote.*
*Voiceover:* "Tiebreak is a global pairwise ranking engine. Instead of submitting subjective top-10 lists, you just vote on binary matchups. React vs Svelte. Vim vs VS Code. Our custom Elo engine handles the rest."

**[0:30 - 0:50] The Leaderboards**
*Visual: Scroll through the virtualized leaderboard, showing the rating and win rates.*
*Voiceover:* "Under the hood, we use a modified Elo system with Wilson lower bounds to ensure the rankings are incredibly accurate. The UI updates instantly via Upstash Redis streams."

**[0:50 - 0:80] Taste Profiles**
*Visual: The user navigates to their Taste Profile, showing their 'Dev Tools DNA' and match percentages.*
*Voiceover:* "But the best part? Tiebreak builds a machine-learning Taste Profile based on your biases. Share your DNA card on Twitter, challenge a friend to a matchup, and see your compatibility score."

**[0:80 - 0:90] Outro**
*Visual: The 'Powered by Tiebreak' embed widget on a blog, ending on the main logo.*
*Voiceover:* "Stop debating. Start voting. Tiebreak is live now."
